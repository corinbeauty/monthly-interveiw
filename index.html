儲存失敗

FirebaseError: [code=permission-denied]

🔑 診斷結果：Firebase 匿名驗證未啟用

此問題是因為您的 Firebase 專案未啟用匿名帳號登入，導致安全通道無法連線。請依照以下步驟啟用：

  1. 開啟並登入您的 Firebase Console
  2. 進入專案 monthly-interview
  3. 點擊左側選單的 Authentication (身分驗證)
  4. 切換到 Sign-in method (登入方法) 標籤頁，點選 Add new provider (新增提供者)
  5. 選擇 Anonymous (匿名) 並將其切換為 啟用 (Enable) 後點擊儲存。

🔒 診斷結果：Firestore 讀寫規則阻擋

此問題是由於您的 Firestore 安全規則仍處於預設的關閉狀態。請依照以下步驟快速修改：

  1. 開啟並登入您的 Firebase Console
  2. 點選進入左側 Firestore Database -> 頂部 Rules (規則) 標籤
  3. 將其修改為以下「解鎖安全通道」代碼（覆蓋原有規則）：
✨ 方法一：全局極速調試規則 (100% 解鎖成功) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
🔒 方法二：專用 artifacts 目錄安全防禦規則 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{document=**} {
      allow read, write: if true;
    }
  }
}

💡 設定發佈後，大約需要 30 秒使安全變更在雲端生效。重新整理網頁後，即可正常讀寫！
