儲存失敗

FirebaseError: [code=permission-denied]

🔒 診斷：Firebase 驗證或規則受阻

您遇到此問題 100% 是因為尚未正確設定 Firestore Rules，或權限遭到阻擋。我們已為您在系統本機建立保護備份。

請至 Firebase Console 的 Firestore Database > Rules，貼上以下代碼並「發佈」：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
